Instalar MAX Representação

Você pode instalar o sistema como um app no seu celular ou PC. Assim ele fica com ícone na tela inicial e abre como aplicativo normal.

Como instalar manualmente:

  1. Chrome no PC: clica no ícone ⊕ na barra de endereço
  2. Chrome no Android: menu ⋮ → Instalar app
  3. Safari no iPhone: botão Compartilhar → Adicionar à Tela Inicial
  4. Edge no PC: menu ... → Aplicativos → Instalar este site
